# 公文自动排版工作台

上传文档 → 自动识别结构 → 按公文规范排版 → 导出 Word

## 功能

- 支持 `.docx` / `.txt` 文件上传，或直接粘贴文本
- 自动识别公文结构：题目、各级标题、正文
- 按公文格式规范自动排版
- 支持手动调整段落类型
- 导出标准 `.docx` 文件

## 排版规范

| 元素 | 字体 | 字号 |
|------|------|------|
| 题目 | 方正小标宋简体 | 二号 (22pt) |
| 正文 | 仿宋_GB2312 | 三号 (16pt) |
| 一级标题 | 黑体 | 三号 (16pt) |
| 二级标题 | 楷体_GB2312 | 三号 (16pt) |
| 三级标题 | 仿宋_GB2312 | 三号 (16pt) |
| 四级标题 | 仿宋_GB2312 | 三号 (16pt) |
| 数字标题 | Times New Roman | 三号 (16pt) |
| 页码 | 宋体 | 四号 (14pt) |

- 行距：固定值 33-36 磅（可调）
- 页边距：上 3.7cm、下 3.5cm、左 2.8cm、右 2.6cm

## 使用方法

1. 用浏览器打开 `workbench-standalone.html`（离线版，无需联网）
2. 上传文件或粘贴文本
3. 系统自动识别结构，可手动调整
4. 点击「导出排版文档」下载 `.docx`

## 文件说明

- `workbench-standalone.html` — 离线版（库已内联，765KB）
- `workbench.html` — 在线版（依赖 CDN，约 30KB）

## 结构识别规则

| 文本模式 | 类型 |
|----------|------|
| 首行 | 题目 |
| 一、二、三、 | 一级标题 |
| （一）（二） | 二级标题 |
| 1. 2. 3. | 三级标题 |
| （1）（2） | 四级标题 |
| 其余 | 正文 |
